# YOGI animation additions

250 additions: eight official GSAP skills from a pinned MIT-licensed GitHub snapshot, plus 242 original YOGI recipes. These are not 250 independently sourced GitHub skills. All 500 previous skills remain unchanged.

Original recipes include focused integration constraints, a component checklist, and a dependency-free motion probe. A probe demonstrates the visual technique; it is not a complete implementation of routing, media, microphone, drag-and-drop, or modal semantics.
