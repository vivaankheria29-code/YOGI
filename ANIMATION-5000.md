# Additional YOGI animation recipes

5,000 original focused recipes: 3,000 video (30 subjects × 10 production tasks × 10 delivery contexts) and 2,000 web 3D (20 subjects × the same task/context matrix). These are combinatorial guidance recipes, not 5,000 independently researched techniques, downloaded GitHub projects, installed rendering engines, or verified implementations.

The previous 750 skills are retained byte for byte. Total: 5,750 entries, comprising 508 GitHub skills and 5,242 custom YOGI recipes. Existing upstream attribution and licenses remain in the catalogue.

New recipes install in workspace/.yogi/skills and are searched/read on demand. The existing 750 retain workspace/.agents/skills discovery. Automatic routing selects at most two guides per turn by default, within a 30,000-character budget. Nothing installs npm packages or executes skill scripts automatically.

Use Settings → Skills to search/filter Video animation or 3D websites, or ask for a relevant development task. Specific subject/task/context words improve matching. New recipes contain their subject invariant, task workflow, delivery constraint, acceptance evidence and a primary documentation link. Actual implementation still needs project-specific testing.
