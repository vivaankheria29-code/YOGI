YOGI — PORTABLE DESKTOP EDITION
Created by Vivaan Kheria
=================================

1. Extract this entire ZIP to a writable folder. Do not run it inside the ZIP.
2. On Windows, double-click START YOGI.cmd.
   On macOS, double-click Start YOGI.command.
   On Linux, run Start YOGI.sh (choose Run/Execute in your file manager).
3. Open Settings > Your AI engine. Choose and sign in to your installed CLI.
   Codex is the default; 13 alternatives are available. See CLI-PROVIDERS.md.
4. The server starts and opens Chrome. Clicking Start again reuses the same
   running copy. An occupied port is skipped automatically.

WHAT IS INCLUDED
YOGI's animated face with lip sync, voice controls, file previews, inline images, chat history UI, uploads, modes, tasks,
web/image search, connected-app support, local reader, and reviewed email
attachments. Dependencies are prebundled: no npm install is needed to run.
Follow-ups reuse the current native Codex conversation, streamed tokens
update only the active message, and repeat starts reuse the running server.

NODE.JS
An installed Node.js 22+ is used when available. Otherwise, the starter
downloads a portable Node 24 LTS runtime from https://nodejs.org into
.runtime/ and checks it against the official SHA-256 manifest before use.
The first such download needs internet access. No administrator install
and no machine-wide PowerShell execution-policy change are required.
Supported runtime download targets: Windows, macOS, and Linux x64/ARM64.
Linux needs curl, tar, and sha256sum or shasum if Node must be downloaded.

CODEX
Use a signed-in Codex desktop app or CLI that supports app-server. Detection
checks PATH, common desktop locations, and Windows npm installations.
If not found, set YOGI_CODEX_PATH to codex.exe, the native Codex binary,
or the npm package's bin/codex.js, then start again.
Official installation help: https://developers.openai.com/codex/cli/
Each computer uses its own Codex account and plugin connections. A CLI
installation without the desktop plugins will have fewer tools.

CHROME
Chrome is preferred automatically. Set YOGI_CHROME_PATH if yours is in
a custom location. If Chrome is absent, the default browser opens instead;
install Chrome for Chrome speech-recognition behavior.

OPTIONAL ELEVENLABS VOICE
Copy .env.example to .env in this folder and add YOUR ElevenLabs key.
No API keys, sign-in tokens, private chats, uploaded files, generated
projects, or runtime logs from the original computer are included.
The assistant chat uses the selected CLI account on this device.

DESKTOP / MOBILE LIMIT
This package runs a local Node server and a locally installed AI CLI. It is not an Android/iOS
app and cannot run on phones or Chromebooks without an appropriate desktop
Linux environment. macOS/Linux launch files may require Execute permission
or an OS trust confirmation. In a terminal: sh 'Start YOGI.command'
(macOS) or sh 'Start YOGI.sh' (Linux). OS restrictions cannot be bypassed
by this ZIP. Windows is tested here; macOS/Linux launchers are included
but have not been executed on those operating systems.

TROUBLESHOOTING
- Keep every extracted file together. Use a folder you can write to.
- Logs: work/server.log and work/server-error.log. Current URL: work/launcher.json.
- For a diagnostic report: START YOGI.cmd --diagnose on Windows, or
  sh 'Start YOGI.sh' --diagnose / sh 'Start YOGI.command' --diagnose.
- A firewall or proxy may block first-run downloads or cloud AI connections.
- The server binds only to 127.0.0.1. It is not publicly hosted.
- The local server remains running after the launch window exits.
  Restarting the computer stops it. The chat's Stop button stops a reply.

SOURCE AND REBUILD
Editable source files are included. The starter runs server.bundle.mjs.
After editing source, install dependencies with npm ci and rebuild using
esbuild with bundle:true, platform:'node', target:'node22', format:'esm',
and a createRequire(import.meta.url) banner; or remove server.bundle.mjs
so the launcher runs server.mjs directly with installed dependencies.
See THIRD-PARTY-NOTICES.txt for bundled dependencies and licenses.

WHAT'S NEW IN YOGI
- Nothing OS look: black and white with one red, dot-matrix type, and
  YOGI's face as a circular LED dot matrix. She blinks, looks around,
  thinks, and lip syncs to her real voice while she speaks. The ring of
  dots turns red while she listens. Prefer the illustrated face? Settings >
  Appearance > Face.
- Waiting is never dead air: a thinking card with live status and short
  facts, a voice warm-up animation, and speech that starts after the first
  sentence instead of after the whole reply.
- Attachments show previews before sending (image thumbnails, file cards
  with type and size) and open in a full preview (images, PDFs, text,
  audio, video). Long pastes become a text file.
- Images YOGI creates are shown in the chat, with open and download links.
- Present mode (P key or the Present button) for showing YOGI on a big
  screen, with large captions of what she is saying.
- Light theme for bright rooms and projectors (Settings > Appearance).
- No ElevenLabs key? YOGI uses the browser's built-in voice instead.
- Press Space to talk; press Space again and your message is sent.
- JANMATE chats and tasks carry over when YOGI opens at the same address
  (normally http://localhost:8341) in the same browser.

HEY YOGI WAKE WORD
In Settings, click Enable wake word and allow microphone access. Say Hey Yogi
followed by your question; a short pause sends it. The setting is remembered.
A short tone acknowledges activation after audio playback is unlocked.
Hey Yogi can interrupt a reply. Temporary speech-service failures reconnect
automatically. Disable wake word in Settings anytime.
Keep YOGI open in Chrome. Browser/OS suspension can stop background listening;
this is not a system-wide wake service when the browser is closed.
Speech recognition may send audio to an online service and needs a connection.
